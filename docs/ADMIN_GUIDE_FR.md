# Guide d'utilisation de l'administration du site

Bienvenue! Ce guide explique comment modifier le site web d'Anfa Counselling &
Psychotherapy vous-même — les textes, les photos, et les couleurs — sans avoir besoin de
connaissances techniques.

## Se connecter

1. Allez à l'adresse `https://[le-domaine-du-site]/admin/login`.
2. Entrez le courriel et le mot de passe qui vous ont été donnés.
3. Si vous vous trompez plusieurs fois de mot de passe, le site vous demandera d'attendre
   quelques minutes avant de réessayer — c'est normal, c'est une protection de sécurité.

Une fois connectée, vous verrez trois sections dans le menu de gauche : **Textes du
site**, **Images**, et **Couleurs & polices**.

## Modifier les textes

Dans **Textes du site**, les textes sont regroupés par page (page d'accueil, page À
propos, FAQ, etc.). Utilisez la barre de recherche en haut pour trouver rapidement un
texte si vous savez à peu près ce que vous cherchez.

Chaque texte existe en français et en anglais — modifiez les deux si vous voulez que le
changement apparaisse dans les deux langues du site.

- Cliquez dans une case de texte et modifiez-la.
- Un bouton **Enregistrer** apparaît dès que vous avez changé quelque chose — cliquez-y
  pour que le changement soit publié sur le site.
- Si vous changez d'avis, le bouton **Réinitialiser** à côté de chaque texte le remet
  exactement comme il était avant — vous ne pouvez rien "casser" de façon permanente.

## Changer une photo

Dans **Images**, vous verrez une carte pour chaque photo remplaçable du site (le logo,
les photos d'accueil, la photo de Sahra, les photos des services, etc.), avec la photo
actuelle et l'endroit où elle apparaît sur le site.

- Cliquez sur une carte ou glissez-y une nouvelle photo pour la remplacer.
- Formats acceptés : JPG, PNG ou WEBP, maximum 5 Mo.
- Un aperçu s'affiche avant que le changement soit publié.
- Le bouton **Réinitialiser à l'image d'origine** ramène toujours la photo de départ si
  besoin.

## Changer les couleurs et les polices

Dans **Couleurs & polices**, vous trouverez plusieurs palettes de couleurs et paires de
polices déjà préparées pour garder une apparence élégante — cliquez simplement sur celle
que vous préférez pour voir un aperçu en direct avant de l'appliquer.

- Cliquez sur **Appliquer sur le site** seulement quand vous êtes satisfaite de l'aperçu.
- Le bouton **Réinitialiser aux couleurs et polices d'origine** ramène toujours
  l'apparence de départ du site.
- Une section "Avancé" permet de choisir des couleurs précises une par une si vous
  voulez personnaliser davantage — à utiliser avec prudence, car il est plus facile de
  s'y perdre.

## Voir le résultat

Le lien **Voir le site →** dans le menu ouvre le site public dans un nouvel onglet, pour
que vous puissiez vérifier vos changements.

## Si quelque chose semble ne pas fonctionner

Rien de ce que vous faites dans l'administration ne peut endommager le site de façon
permanente — chaque section a un bouton pour revenir en arrière. Si vous avez un doute ou
rencontrez un message d'erreur qui persiste, contactez la personne qui gère le site
techniquement avant de continuer.

## Se déconnecter

Cliquez sur **Se déconnecter** dans le menu de gauche en terminant, surtout si vous
utilisez un ordinateur partagé.
